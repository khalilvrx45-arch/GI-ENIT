## 📌 À propos du projet

Cette plateforme permet de gérer et de promouvoir les activités du club **CGI-ENIT** :
* 📅 **Événements & Workshops :** Consultation et inscription aux événements / hackathons.
* 👥 **Membres & Bureau :** Présentation des membres et de l'équipe exécutive.
* 📝 **Blog / Actualités :** Articles techniques et récapitulatifs des activités du club.
* 📩 **Contact & Adhésion :** Formulaires d'interaction directe avec le club.

---

## 🛠️ Stack Technique

| Domaine | Technologies |
| :--- | :--- |
| **Frontend** | React.js / Next.js, Tailwind CSS, Lucide React (Icones) |
| **State Management** | Zustand / TanStack Query |
| **Outillage** | Vite / Next.js, ESLint, Prettier |
| **CI/CD & Deploy** | GitHub Actions, Vercel / Netlify |
